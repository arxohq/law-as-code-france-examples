относятся к возможности взыскания во время обжалования; это не решение
CRA по существу долга. L.845-2 требует предварительного обращения в CRA;
L.845-3 регулирует приостановление. Жилищная remise по R.825-3 — отдельная
процедура, не универсальный срок обжалования гражданином.

# Cohorte fictive — base et allocations familiales

Martin, Bernard et Petit ont deux, trois et quatre enfants, sans majorations d’âge. Durand a un enfant. Lecture explicite fr.pf.af::ArrondiLignesDss. Les données, questions, tests et réplique manuelle sont conservés dans ce dossier. Le coefficient de revalorisation est calculé dans un autre canon; ici la BMAF est une entrée.

```sh
python3 check.py --law <chemin-absolu-vers-law>
law test . --json
```

Exécution locale dans le checkout avec Python 3.12 ou supérieur et un binaire
`law` sauvegardé. Les canons français ne sont pas encore publiés pour une
installation indépendante. Les sources et la réplique sont dans `sources/`.
Les résultats enregistrés en octobre 2026 ne remplacent pas une vérification juridique.
